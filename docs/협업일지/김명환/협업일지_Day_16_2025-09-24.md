## [5] 오늘 분석/실험 중 얻은 인사이트나 발견한 문제점은?
**답변**:  
**발표 준비 과정에서의 인사이트:**
1. **스토리텔링의 중요성**: 기술적 성과를 스토리로 구성할 때 더 효과적인 전달 가능
2. **시각화 효과**: 복잡한 모델 구조도 적절한 시각화로 쉽게 이해 가능
3. **실무 연결성**: 기술적 구현을 실제 사용 사례와 연결해 설명할 때 임팩트 증대
4. **팀워크 시너지**: 각자의 강점을 살린 역할 분담이 전체 발표 품질 향상에 기여

**발견된 문제점:**
- 일부 기술 용어가 청중에게 어려울 수 있음
- 데모 환경에서 모델 로딩 시간이 다소 길어질 가능성
- 발표 시간 조절의 어려움 (내용이 풍부해 시간 초과 우려)
