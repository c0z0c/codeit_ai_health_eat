## 1. 분석 목적

점수가 높게 나온 모델과 낮게 나온 모델을 비교 분석하여 **객체 탐색 및 분류 시 오류 원인을 추적**하고, 향후 모델 성능 개선을 위한 인사이트를 도출하고자 한다.

---

## 2. 주요 발견사항

### 2.1. 모델 성능 비교

| 모델 | 정확도 | 데이터 출처 | 특징 |
|------|--------|-------------|------|
| **빨강색 모델** | **97%** | 코드잇 제공 + AI HUB 추가 데이터 | 높은 정확도, 안정적 성능 |
| **파란색 모델** | **88%** | 코드잇 제공 데이터만 사용 | 상대적으로 낮은 정확도 |

**성능 차이: 9%p**

### 2.2. 검출 결과 분석

**주요 관찰사항:**
- AI HUB 데이터 추가 후 정확도 향상 (88% → 97%)
- 일부 카탈로그 ID에서 라벨링 불일치 발견
- 색상 변화에 민감한 알약 분류 특성 확인

## 3. 오류 원인 분석

### 3.1. 훈련 데이터 불완전성

**문제점:**
- 특정 알약 클래스가 Train 데이터셋에 누락
- 예시: 979_comparison.jpg에서 카탈로그 ID 4999 (예상: K-005000)에 대한 어노테이션 부재

<img src="https://c0z0c.github.io/codeit_ai_health_eat/%EB%B0%9C%ED%91%9C%EC%9E%90%EB%A3%8C/%EA%B0%9D%EC%B2%B4%ED%83%90%EC%83%89%EC%98%A4%EA%B2%80%EC%B6%9C%EB%B6%84%EC%84%9D%EB%B3%B4%EA%B3%A0%EC%84%9C/979_comparison.jpg" width="640px"/>

**영향:**
- 파란색 모델이 존재하지 않는 알약에 대해 높은 score 부여
- 실제로는 잘못된 분류임에도 confidence가 높게 나타남

### 3.2. 데이터 불균형 및 오염

**데이터 불균형:**
- 클래스 간 샘플 수 차이로 인한 편향 학습
- 소수 클래스에 대한 과소 학습 발생

**데이터 오염 우려:**
- AI HUB 추가 데이터에서의 잠재적 품질 이슈
- 라벨링 일관성 검증 필요

### 3.3. 알약 도메인 특수성

**알약 분류의 핵심 요소:**

1. **색상 의존성**
   - 알약은 색상이 중요한 분류 기준
   - 밝기 조절, 색상 변환 등의 augmentation은 **사용 금지**
   - 허용 augmentation: 회전, 각도 조절만 가능

2. **유사한 형태학적 특성**
   - 동일한 모양의 알약이 다수 존재
   - 음각된 글자 및 색상으로 구분
   - Fine-grained classification의 전형적 사례

3. **미세한 텍스처 차이**
   - 표면의 희미한 각인(embossing)
   - 조명 조건에 따른 가시성 변화
   - 고해상도 특징 추출 필요
