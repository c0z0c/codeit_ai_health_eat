## 1. 서론 및 실험 개요

### 1.1. 연구 배경
의료 분야 알약 분류는 환자 안전과 직결된 중요한 과제로, **99% 이상의 정확도**가 요구되는 고정밀 분류 문제이다. 특히 **색상과 모양이 유사한 알약들**을 구분하는 것은 Fine-grained Visual Classification의 대표적 사례로, 기존 범용 객체 탐지 모델들의 한계를 드러내는 영역이다.

### 1.2. 실험 목적 및 가설
**주요 목적:**
- ResNet-101 (독립모델)과 EfficientNet (2-stage) 성능 비교
- 2-stage 파이프라인에서의 성능 저하 원인 규명
- 색상/모양 유사 알약 분류에서의 모델별 특성 분석

**연구 가설:**
- H1: ResNet-101의 깊은 네트워크 구조가 미세한 알약 특징 추출에 유리할 것
- H2: 2-stage 파이프라인에서 오차 누적(Error Propagation)이 성능 저하를 야기할 것
- H3: 데이터셋 품질이 2-stage 모델 성능에 결정적 영향을 미칠 것

### 1.3. 모델 구성
**독립모델:** FNN + ResNet-101 (97% 정확도)
**2-stage 모델:** YOLO (객체 탐지) + EfficientNet (분류) (88% 정확도)

## 5. 2-Stage 파이프라인 성능 저하 원인 분석

### 5.1. Error Propagation (오차 누적) 효과

**1단계 (YOLO 객체 탐지) 오류:**
- 부정확한 바운딩 박스
- 알약 경계 부분 누락
- 배경 정보 과도한 포함

**2단계 (EfficientNet 분류) 오류:**
- 잘못 크롭된 이미지 입력
- 중요 특징 (각인, 텍스처) 손실
- 컨텍스트 정보 부족

**복합 오류 효과:**
```
YOLO 오류율 (5%) × EfficientNet 오류율 (8%) = 복합 오류율 (12%)
→ 최종 정확도: 88%
```

### 5.2. 데이터셋 품질 이슈

**바운딩 박스 라벨링 문제:**
- IoU < 0.9인 부정확한 박스
- 알약 가장자리 정보 손실
- 크롭 과정에서 해상도 저하

**알약 도메인 특성 미고려:**
- 미세한 각인 텍스트 보존 실패
- 표면 질감 정보 손실
- 조명 조건 변화에 따른 가시성 저하

### 5.3. 모델 아키텍처 한계

**EfficientNet의 의료 도메인 부적합성:**

**Compound Scaling의 한계:**
```
효율성 최적화: α·β²·γ² ≈ 2
정밀도 요구사항: Fine-grained feature 필요
→ Trade-off 충돌
```

**ResNet-101의 알약 분류 적합성:**
```
깊은 네트워크 (101 layers)
→ 미세한 텍스처 패턴 학습 가능
→ 색상/모양 유사 알약 구분 성공
```

## 6. 개선 방안 및 제언

### 6.1. 데이터셋 재구성 전략

**1. 바운딩 박스 품질 향상**
```python
# IoU threshold 상향 조정
min_iou_threshold = 0.95

# 알약 전체 포함을 위한 margin 추가
bbox_margin = 0.1  # 10% 여유 공간

# 고해상도 크롭 유지
min_crop_resolution = 224x224
```

**2. 클래스 균형 조정**
```python
# 극소 샘플 category 보강
category_33877: 7개 → 50개 (Data Augmentation)
category_31884: 85개 → 90개 (균형 유지)

# 유사 알약 그룹별 균등 분포
similar_pair_balance = {
    (25366, 10223): 90개씩,
    (34596, 30307): 90개씩
}
```

### 6.2. 모델 아키텍처 개선

**RegNet 적용 계획:**
```python
# ResNet-101 장점 계승
depth_strategy = "deep_network"  # >50 layers
feature_extraction = "high_resolution"

# Fine-grained 특화 기법
attention_mechanism = "channel_attention"
loss_function = "triplet_loss + cross_entropy"
```

**Hard Pair Mining 적용:**
```python
# 유사 알약 쌍 집중 학습
hard_pairs = [
    (25366, 10223),  # 색상/모양 유사
    (34596, 30307),  # 형태학적 유사
    (22073, 4999)    # 표면 질감 유사
]
```

### 6.3. 2-Stage 파이프라인 최적화

**End-to-End 학습 도입:**
```python
# YOLO + Classifier 공동 학습
joint_training = True
shared_backbone = "ResNet-101"

# 그래디언트 공유로 오차 누적 최소화
gradient_flow = "bidirectional"
```

**품질 검증 파이프라인:**
```python
# 크롭 품질 실시간 검증
crop_quality_check = {
    "feature_preservation": 0.95,  # 특징 보존율
    "resolution_maintenance": 224,  # 최소 해상도
    "context_inclusion": 0.1       # 컨텍스트 비율
}
```

### 6.4. 성능 목표 및 검증 전략

**목표 성능:**
- **전체 정확도**: 97% → 99%+
- **유사 알약 구분 정확도**: 85% → 95%+
- **의료 안전 기준**: 99.9% 신뢰도 달성

**검증 방법론:**
```python
# 유사 알약 쌍별 분리 평가
similar_pair_accuracy = evaluate_similar_pairs(test_set)

# 실제 의료진 정확도와 비교
medical_professional_benchmark = 0.995
model_target_accuracy = medical_professional_benchmark * 1.001
```

## 7. 용어 목록

| 용어 | 영문 | 설명 |
|------|------|------|
| 파인 그레인드 분류 | Fine-grained Classification | 매우 유사한 객체들 간의 세밀한 차이를 구분하는 분류 문제 |
| 오차 누적 | Error Propagation | 다단계 파이프라인에서 앞 단계의 오류가 뒷 단계로 전파되는 현상 |
| 하드 페어 마이닝 | Hard Pair Mining | 구분하기 어려운 유사 객체 쌍을 집중적으로 학습하는 기법 |
| 컨트라스트 손실 | Contrastive Loss | 유사한 샘플은 가깝게, 다른 샘플은 멀게 배치하도록 학습하는 손실 함수 |
| 트리플렛 손실 | Triplet Loss | 앵커, 양성, 음성 샘플 3개를 이용한 거리 기반 학습 기법 |
| 아이오유 임계값 | IoU Threshold | 객체 탐지에서 예측 박스와 실제 박스의 겹침 정도 기준 |
| 복합 스케일링 | Compound Scaling | 네트워크 깊이, 너비, 해상도를 동시에 조절하는 EfficientNet 전략 |
| 잔차 연결 | Residual Connection | 입력을 출력에 직접 연결하여 그래디언트 소실을 방지하는 ResNet 기법 |
| 채널 어텐션 | Channel Attention | 특징 맵의 채널별 중요도를 학습하여 성능을 향상시키는 기법 |
| 엔드투엔드 학습 | End-to-End Learning | 입력부터 출력까지 전체 파이프라인을 통합적으로 학습하는 방법 |

본 연구를 통해 알약 분류 도메인에서 **ResNet-101의 우수성**과 **2-stage 파이프라인의 한계**를 명확히 확인했다. 특히 **색상/모양 유사 알약 구분**이라는 Fine-grained Classification 과제에서는 깊은 네트워크 구조와 고품질 데이터셋이 필수적임을 입증했다.
